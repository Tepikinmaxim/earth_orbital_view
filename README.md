# TERRA — интерактивная 3D-планета Земля

Репозиторий: <https://github.com/Tepikinmaxim/earth_orbital_view>

Веб-приложение с фотореалистичной 3D-Землёй: управление освещением, сезонами,
слоями и вращением планеты, а также поиск городов с метками на глобусе.

## Возможности

- **Освещение:** режимы «День», «Ночь» и «Сейчас» (терминатор по реальному UTC).
- **Сезоны:** зима, весна, лето, осень — наклон оси и склонение Солнца.
- **Слои:** облака, огни городов, атмосфера, звёзды, Солнце, Луна.
- **Вращение:** скорость от «Стоп» до 3× (1× — реальное время).
- **Поиск городов:** офлайн-база 230+ городов мира, мгновенные подсказки,
  дополнительно прокси к Open-Meteo Geocoding для остальных городов.
- **Метки:** до 6 городов одновременно — красная пульсирующая звезда, подпись,
  полёт камеры и слежение за выбранным городом.
- **Управление камерой:** перетаскивание — вращение, колесо — зум,
  двойной клик или кнопка «Сбросить камеру» — возврат.
- **Адаптивность:** на мобильных панель настроек становится нижним листом.
- **Полноэкранный режим:** кнопка рядом с настройками; скрывается, если браузер
  не поддерживает Fullscreen API.

## Требования

- Node.js 20.9+ (проверено на 22.22.2)
- npm (используется для установки и разработки)
- Интернет — для установки зависимостей, загрузки шрифтов Next.js
  и подсказок геокодера (офлайн-база работает без сети)

Bun в этом проекте **не требуется** для разработки. Файл `bun.lock` и
production-скрипт `start` рассчитаны на Bun, но на macOS 12 Monterey
актуальные версии Bun могут быть недоступны.

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Откройте <http://localhost:3000>. Лог пишется в `dev.log`.

Если порт 3000 занят, запустите на другом порту:

```bash
npx next dev -p 3001
```

## Сборка и production

```bash
npm run build
```

Скрипт собирает standalone-версию и копирует `.next/static` и `public`
в `.next/standalone/`.

```bash
npm run start
```

`npm run start` вызывает `bun .next/standalone/server.js` и требует
установленный Bun. Без Bun можно запустить напрямую:

```bash
NODE_ENV=production node .next/standalone/server.js
```

## Проверка

```bash
npm run lint
curl -I http://localhost:3000
curl "http://localhost:3000/api/geocode?q=Москва"
```

## API

| Маршрут | Метод | Описание |
| --- | --- | --- |
| `/api` | GET | `{ "message": "Hello, world!" }` |
| `/api/geocode?q=<город>` | GET | `{ "results": [{ id, name, country, lat, lon, source }] }` |

Геокодер проксирует бесплатный Open-Meteo (ключ не нужен). При таймауте
(3,5 с) или отсутствии сети возвращает пустой список — поиск продолжает
работать по локальной базе.

## Структура

```
src/
  app/
    page.tsx              — экран приложения, панель управления, поиск
    layout.tsx            — метаданные, шрифты, общий layout
    globals.css           — глобальные стили, стили подписей городов
    api/route.ts          — тестовый эндпоинт
    api/geocode/route.ts  — прокси геокодера Open-Meteo
  lib/
    earthScene.ts         — ядро three.js: шейдеры, сцена, камера, метки
    cities.ts             — офлайн-база городов и локальный поиск
    db.ts, utils.ts       — Prisma-клиент (не используется UI) и cn()
  components/ui/          — компоненты shadcn/ui
  hooks/                  — вспомогательные хуки
public/textures/          — текстуры Земли, облаков, воды и Луны
prisma/, db/              — заготовка Prisma/SQLite (приложением не используется)
examples/, mini-services/ — примеры и заготовки, не участвуют в запуске
tests/                    — shell-скрипты сборки runtime-образов
scripts/                  — скриншоты прошлых проверок
worklog.md                — журнал выполненных задач
plan.md                   — план работ и результаты проверки
```

## Известные ограничения

- Поиск вне офлайн-базы зависит от доступности Open-Meteo.
- `next.config.ts` игнорирует ошибки TypeScript при сборке
  (`ignoreBuildErrors: true`) — типы отдельно не проверяются.
- Prisma/SQLite и примеры WebSocket остались от шаблона и не используются.
- Автоматических тестов нет: `tests/*.sh` — скрипты сборки окружения,
  не тесты приложения.
- На iPhone (iOS Safari) Fullscreen API недоступен — кнопка полноэкранного
  режима там не отображается.
- `npm run lint` выдаёт 2 ошибки в шаблонных компонентах
  `src/components/ui/carousel.tsx` и `src/hooks/use-mobile.ts`
  (`react-hooks/set-state-in-effect`); к экрану приложения они не относятся.
