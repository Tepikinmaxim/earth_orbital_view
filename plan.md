# План работ — TERRA (earth_orbital_view)

## Цель текущей задачи

Познакомиться с проектом, подготовить документацию и запустить приложение
локально для проверки работоспособности.

## Что выяснено при изучении

- Проект: Next.js 16 + React 19 + TypeScript + Tailwind v4 + shadcn/ui,
  3D на three.js 0.186.
- Основная логика: `src/lib/earthScene.ts` (шейдеры, сцена, камера, Луна,
  метки городов), UI — `src/app/page.tsx`.
- Офлайн-база городов `src/lib/cities.ts`, прокси геокодера
  `src/app/api/geocode/route.ts`.
- `node_modules` и `.next` отсутствовали; Bun не установлен.
- Prisma/SQLite (`src/lib/db.ts`, `prisma/`, `db/custom.db`) и
  `examples/websocket` приложением не используются.

## Этапы

1. **Документация** — создать `README.md` и `plan.md` на русском
   с описанием стека, запуска, структуры и ограничений.
2. **Зависимости** — `npm install` (без Bun: на macOS 12 Monterey
   актуальный Bun может быть недоступен).
3. **Запуск** — `npm run dev` в фоне на порту 3000, лог в `dev.log`.
4. **Проверка** — HTTP-статус главной, `/api/geocode?q=Москва`,
   отсутствие ошибок компиляции в `dev.log`.
5. **Итог** — зафиксировать результат и известные проблемы в этом файле.

## Результаты

**Выполнено 27.10.2026.**

1. Созданы `README.md` и `plan.md` на русском.
2. `npm install` — установлено 854 пакета, точка входа Next.js 16.4.3.
   Bun не использовался.
3. Порт 3000 занят посторонним процессом (`next-server`, PID 28417,
   каталог `~/.zcode/workspace/default`), поэтому сервер запущен на 3001:
   `npx next dev -p 3001`, лог в `dev.log`, PID 29251.
4. Проверки:
   - `GET /` — HTTP 200, страница содержит `TERRA`;
   - `GET /api/geocode?q=Москва` — HTTP 200, вернулись результаты Open-Meteo;
   - `GET /api` — HTTP 200, `{"message":"Hello, world!"}`;
   - текстуры `/textures/earth-day.jpg` и `/textures/moon.jpg` — HTTP 200;
   - в `dev.log` ошибок и предупреждений нет.
5. `npm run lint` — 2 предсуществующие ошибки
   `react-hooks/set-state-in-effect` в шаблонных
   `src/components/ui/carousel.tsx` и `src/hooks/use-mobile.ts`.
   К приложению не относятся, не исправлялись в рамках задачи.

Приложение доступно на <http://localhost:3001>. Остановка:
`kill 29251` (или `kill 29250`, если нужен родительский процесс).

## Дополнение: кнопка «На весь экран»

**Выполнено 27.10.2026.**

- В `src/app/page.tsx` добавлена кнопка-переключатель справа сверху, левее
  кнопки настроек: `Maximize2` / `Minimize2`, подписи «На весь экран» и
  «Выйти из полноэкранного режима».
- Используются `document.documentElement.requestFullscreen()` и
  `document.exitFullscreen()`; состояние синхронизируется через
  `useSyncExternalStore` по событию `fullscreenchange` (без setState в эффекте).
- Если `document.fullscreenEnabled` равно `false` (например, iPhone), кнопка
  не показывается.
- Проверки: `npx eslint src/app/page.tsx` — без ошибок; `GET /` — HTTP 200;
  в `dev.log` ошибок компиляции нет. Визуальная проверка клика в браузере
  не выполнялась — браузерных инструментов в окружении нет.
- Изменённые файлы: `src/app/page.tsx`, `README.md`, `plan.md`.
